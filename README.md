The funniest single-line resignation letter: fourteen days' notice, one office plant, and a clean getaway.

> You have 14 days to find someone else to water the office plant, because I just resigned and took the plant with me.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
